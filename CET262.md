### **1. Virtual Machine Creation**  
- **Task**: Create a VM with 40GB disk (split into multiple files), 2GB RAM, and default CPU.  
- **Tools**: Use VirtualBox, VMware, or QEMU.  
*Example for VirtualBox:*  
```bash
VBoxManage createvm --name "ArchBaremetal" --register
VBoxManage modifyvm "ArchBaremetal" --memory 2048 --cpus 1
VBoxManage createmedium disk --filename arch.vdi --size 40960 --format VDI --variant Split
VBoxManage storagectl "ArchBaremetal" --name "SATA Controller" --add sata
VBoxManage storageattach "ArchBaremetal" --storagectl "SATA Controller" --port 0 --device 0 --type hdd --medium arch.vdi
```

### **2. Arch Linux Installation**  
- **Boot Arch ISO**: Attach the Arch ISO to the VM and boot.  

#### **Partitioning (BIOS/MBR Example)**  
```bash
# Identify disk (e.g., /dev/sda)
lsblk

# Partition disk
fdisk /dev/sda
# Create partitions:
# 1. /boot (512M, type 83 Linux)
# 2. /home (14G, type 83 Linux)
# 3. / (25.5G, type 83 Linux)
# Write changes and exit

# Format partitions
mkfs.ext4 /dev/sda1    # /boot
mkfs.ext4 /dev/sda2    # /home
mkfs.ext4 /dev/sda3    # /

# Mount partitions
mount /dev/sda3 /mnt
mkdir /mnt/boot /mnt/home
mount /dev/sda1 /mnt/boot
mount /dev/sda2 /mnt/home
```

#### **Install Base System**  
```bash
pacstrap /mnt base linux linux-firmware vim sudo openssh
genfstab -U /mnt >> /mnt/mnt/fstab
arch-chroot /mnt
```

### **3. System Configuration**  
#### **Set Root Password**  
```bash
passwd  # Set a strong password
```

#### **Create Administrative Users**  
```bash
# For yourself
useradd -m -G wheel <your_username>
passwd <your_username>

# For Ashley (IT Manager)
useradd -m -G wheel ashley
passwd ashley

# Enable sudo for wheel group
echo "%wheel ALL=(ALL) ALL" >> /etc/sudoers
```

#### **Secure Root Account**  
- Disable root SSH login and enforce sudo:  
```bash
echo "PermitRootLogin no" >> /etc/ssh/sshd_config
```

### **6. Configure /srv Directory Permissions**  
```bash
mkdir -p /srv/http
# Create groups
groupadd developers
groupadd testers

# Assign users to groups
usermod -aG developers avery
usermod -aG developers evelynn
usermod -aG testers james

# Set permissions
chown -R :developers /srv
chmod -R 2775 /srv      # SGID to inherit group
setfacl -R -m g:testers:rx /srv  # Testers can read only
```

### **7. Docker Setup**  
#### **Install Docker**  
```bash
pacman -S docker docker-compose
systemctl enable docker
systemctl start docker
# Add users to docker group
usermod -aG docker avery
usermod -aG docker <your_username>
usermod -aG docker ashley
```

#### **Create Docker Compose File**  
```bash
mkdir /srv/docker
vim /srv/docker/docker-compose.yml
```
*Add the following configuration:*  
```yaml
version: '3'
services:
  mysql:
    image: mysql:latest
    environment:
      MYSQL_ROOT_PASSWORD: "securepassword"
    volumes:
      - mysql_data:/var/lib/mysql
    networks:
      - internal

  phpmyadmin:
    image: phpmyadmin:latest
    depends_on:
      - mysql
    environment:
      PMA_HOST: mysql
    networks:
      - internal
      - proxy
    labels:
      - "traefik.http.routers.phpmyadmin.rule=PathPrefix(`/phpmyadmin`)"

  nginx:
    image: nginx:latest
    ports:
      - "80:80"
    volumes:
      - /srv/http:/usr/share/nginx/html
    networks:
      - proxy

networks:
  internal:
    internal: true
  proxy:

volumes:
  mysql_data:
```

#### **Start Containers**  
```bash
cd /srv/docker
docker-compose up -d
```

#### **Create MySQL Admin User (Avery)**  
```bash
docker exec -it docker_mysql_1 mysql -u root -p
# Enter password: securepassword
CREATE USER 'avery'@'%' IDENTIFIED BY 'averypassword';
GRANT ALL PRIVILEGES ON *.* TO 'avery'@'%';
FLUSH PRIVILEGES;
```

### **Final Notes**  
- **Justification**:  
  - Root login disabled via SSH to prevent brute-force attacks.  
  - `sudo` restricts administrative privileges to trusted users.  
  - Docker group membership ensures only authorized users control containers.  
  - ACLs enforce developer/tester access rules for `/srv`.
